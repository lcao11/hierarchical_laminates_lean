# Companion reading

These documents accompany Lianghao Cao's [manuscript](https://arxiv.org/abs/2610.37899) on planar two-phase composites and the two-well energy gap.

| Document | What it offers |
| --- | --- |
| [Research progress report](research-progress-report.pdf) | *The Path to the Counterexample*: an account of the ideas, alternative approaches and choices leading to the construction. |
| [Proof exercises](proof-exercises.pdf) | 178 guided steps in twelve modules, with prerequisites, difficulty labels, notation links and background results. |
| [Worked answers](worked-answers.pdf) | Solutions using the same step numbers. Every question is repeated alongside its answer. |

For the main results, begin with the manuscript. Read the report for the mathematical context and the approaches that led to the construction. To work through the proofs, follow the exercise modules in order and consult the answers after attempting each step. The answer book also supports a continuous reading of the argument with the questions included.

For the formal proofs, use the [statement guide](../Statements.md) and [proof guide](../ProofGuide.md).

The manuscript's DOI is [10.48550/arXiv.2610.37899](https://doi.org/10.48550/arXiv.2610.37899). A [BibTeX citation](../../CITATION.bib) is available at the repository root.
